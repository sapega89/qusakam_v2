# Charm icons (A6)

`Scripts/Tools/comfy_icons.py --charms`: one 36×36 icon per charm in `Resources/Data/charms.json`, in the manner of the
item icons next door (the grey framed tile of `crystal.png`, a dark line glyph about 20 px).

AI-generated: the glyphs are drawn by the local ComfyUI with **Qwen-Image** (Alibaba Qwen, Apache 2.0) + the
Qwen-Image-Lightning LoRA (lightx2v, Apache 2.0), then reduced to the glyph's alpha by the script. A Steam release has
to disclose AI-generated content.
