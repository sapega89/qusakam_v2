# banner

Idle loop sheet, see `../README.md` (frames, size, anchor). AI-generated: drawn by the local ComfyUI with **Qwen-Image** (Alibaba Qwen, Apache 2.0) + the Qwen-Image-Lightning LoRA (lightx2v, Apache 2.0), then keyed, downscaled to the game pixel and quantised by a script. A Steam release has to disclose AI-generated content.

Redrawn after review (seed 103): one base frame — brick red / teal / brick red stripes, swallow-tail hem, full rod with both knobs, 1 px empty row above it; frames 2–4 are that frame with rows shifted by whole pixels (rod fixed, tip ±2 px). Licence of the models: Apache 2.0.
