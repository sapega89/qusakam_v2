# UI sounds (D274, D275)

From Kenney's **Interface Sounds** (https://kenney.nl/assets/interface-sounds), **CC0**. Played by the Maaacks
`ProjectUISoundController` autoload (`addons/maaacks_menus_template/.../project_ui_sound_controller.tscn`):
`tick_002` — a button gets focus (mouse or pad) and an item list selection, `click_001` — a button press,
`switch_002` — a tab change, `scroll_001` — a slider released.
