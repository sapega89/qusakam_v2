# Ambience loops (D275, D276)

30-s loops built by `Scripts/Tools/audio/build_audio.py world` (filtered, mixed, cross-faded into themselves) from
**CC0** recordings on OpenGameArt (https://creativecommons.org/publicdomain/zero/1.0/). Room → loop: `rooms` in
`SampleProject/Resources/Data/sound_events.json`.

| Loop | Rooms | Sources |
|---|---|---|
| `amb_desert_wind` | DesertRoad, LaboratoryOutside | "Mild Wind Background Noise" by bashar3a — https://opengameart.org/content/mild-wind-background-noise (low-passed) |
| `amb_canyon_echo` | Canyon | "Loopable Dungeon Ambience" by jaggedstone — https://opengameart.org/content/loopable-dungeon-ambience + the wind |
| `amb_village` | Village, CityGates | the wind + "Crowd Shouting/Speaking Ambience" by starninjas — https://opengameart.org/content/crowd-shoutingspeaking-ambience (band-passed: far away) |
| `amb_city_crowd` | City | the crowd (band-passed) + a little wind |
| `amb_hall` | MayorHall | the crowd behind walls (150–900 Hz) |
| `amb_lab_hum` | Laboratory | "Low Rumbling" by musheran — https://opengameart.org/content/low-rumbling (low-passed) |
