# 🚀 Швидкий старт для тестування проходження

## Що було зроблено

✅ Всі переходи між сценами реалізовано
✅ Всі об'єктиви додано
✅ Відсутні діалоги створено
✅ Фінальний екран готовий (потрібно створити сцену)

## Швидке тестування

### 1. Створити DemoEndScreen.tscn

Відкрити `docs/DEMO_END_SCREEN_SETUP.md` та створити сцену згідно з інструкцією.

### 2. Запустити гру

1. Запустити гру (F5)
2. Почати нову гру
3. Пройти від Canyon до LaboratoryOutside
4. Перевірити, що всі переходи працюють
5. Перевірити, що об'єктиви оновлюються
6. Перевірити фінальний екран

### 3. Перевірити переходи

- ✅ Canyon → Village (через Portal)
- ✅ Village → DesertRoad (через Portal)
- ✅ DesertRoad → CityGates (автоматично)
- ✅ CityGates → Laboratory (автоматично)
- ✅ Laboratory → LaboratoryOutside (автоматично)
- ✅ LaboratoryOutside → DemoEndScreen (автоматично)

### 4. Перевірити об'єктиви

На кожному етапі перевірити, що об'єктив оновлюється в UI (якщо є ObjectiveHUD).

## Можливі проблеми

### Проблема: Перехід не працює

**Рішення:**
- Перевірити, що `Game.get_singleton()` повертає не null
- Перевірити, що `Game.load_room()` викликається
- Перевірити консоль на помилки

### Проблема: Об'єктив не оновлюється

**Рішення:**
- Перевірити, що `Game.set_objective()` викликається
- Перевірити, що ObjectiveHUD підключений до сигналу `objective_updated`

### Проблема: Фінальний екран не показується

**Рішення:**
- Перевірити, що DemoEndScreen.tscn створено
- Перевірити, що шлях до сцени правильний
- Перевірити консоль на помилки
