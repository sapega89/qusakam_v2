# 🔧 Виправлення збереження стану сцени при переходах

## Проблема

При переході між сценами (особливо при поверненні з Village до Canyon) стан сцени не зберігається правильно, що призводить до:
- Ворота залишаються закритими, навіть коли вони мають бути відкриті
- Гравець не може пройти далі, бо ворота блокують прохід

## Причина

1. **Проблема з ініціалізацією GateControllers**: GateControllers ініціалізуються асинхронно (через `await get_tree().process_frame`), тому коли `_determine_initial_state()` викликається, GateControllers можуть ще не бути готові.

2. **Ворота не оновлюються при поверненні**: Коли гравець повертається з Village, стан визначається як `RELIC_PICKUP`, але ворота можуть не оновитися, якщо GateControllers ще не ініціалізувалися.

3. **Відсутність затримки перед оновленням воріт**: `_update_gates_for_state()` викликається одразу після визначення стану, але GateControllers можуть ще не бути готові.

## Виправлення

### 1. Додано затримку перед оновленням воріт

**Файл:** `SampleProject/Scripts/Gameplay/Scenes/Canyon.gd`

- Додано `await get_tree().process_frame` після визначення початкового стану
- Це дає час GateControllers ініціалізуватися перед оновленням воріт

### 2. Покращено `_update_gates_for_state()`

- Додано повторну спробу знайти GateControllers, якщо вони не знайдені
- Додано затримку перед повторною спробою
- Додано детальне логування для діагностики

### 3. Використання `call_deferred` для оновлення воріт

- В `_on_state_changed()` використовується `call_deferred("_update_gates_for_state", new_state)`
- Це гарантує, що GateControllers будуть готові до моменту оновлення

### 4. Покращено логіку для стану RELIC_PICKUP

- Додано явне встановлення `_previous_state` при визначенні стану `RELIC_PICKUP`
- Додано логування про важливість відкриття воріт при поверненні

## Логіка воріт для стану RELIC_PICKUP

При стані `RELIC_PICKUP` (повернення з Village):
- **Gate (до Village)**: ВІДКРИТІ - гравець може повернутися до Village
- **Gate2 (до дороги)**: ВІДКРИТІ - гравець може йти далі до дороги

## Перевірка

Після виправлень перевірте:

1. ✅ При поверненні з Village до Canyon ворота відкриваються правильно
2. ✅ Стан `RELIC_PICKUP` встановлюється коректно
3. ✅ GateControllers знаходяться та оновлюються правильно
4. ✅ Гравець може пройти через ворота назад до Village або далі до дороги
