# 📊 Налаштування логування для діагностики телепортації

## Проблема з DebugLogger

**DebugLogger за замовчуванням має рівень `WARNING`**, тому `DebugLogger.info()` не виводиться в консоль!

## Рішення

### 1. Використання `print()` для критичних повідомлень

Додано `print()` для всіх критичних повідомлень, щоб вони завжди виводилися:

```gdscript
# Завжди виводиться
print("✅ [Game] _ready() викликано вперше")
print("⚠️ [Game] _ready() вже викликано - гра перестворюється!")
print("🚪 [Game] load_room() викликано #%d" % _load_room_call_count)
print("📍 [Game] Позиція гравця: %s" % player.global_position)
```

### 2. Зміна рівня DebugLogger (опціонально)

Якщо потрібно бачити всі `DebugLogger.info()` повідомлення:

```gdscript
# В Game._ready() або в іншому місці ініціалізації
DebugLogger.set_level(DebugLogger.LogLevel.INFO)
```

## Ключові повідомлення для діагностики

### Перевірка перестворення гри:

```
✅ [Game] _ready() викликано вперше, ініціалізуємо гру
```
**Очікується:** 1 раз при запуску гри

```
⚠️ [Game] _ready() вже викликано (_bootstrapped=true), пропускаємо ініціалізацію
⚠️ [Game] ЦЕ МОЖЕ БУТИ ПРИЧИНОЮ ПОДВІЙНОЇ ТЕЛЕПОРТАЦІЇ - гра перестворюється!
```
**Проблема:** Гра перестворюється, `_ready()` викликається кілька разів!

### Перевірка завантаження кімнат:

```
🚪 [Game] load_room() викликано #1: room_ref='Canyon.tscn', path='res://SampleProject/Maps/Canyon.tscn'
```
**Очікується:** При кожному переході між кімнатами

```
⚠️ [Game] load_room() викликано ДРУГИЙ РАЗ для тієї ж кімнати: res://SampleProject/Maps/Canyon.tscn
⚠️ [Game] ЦЕ МОЖЕ БУТИ ПРИЧИНОЮ ПОДВІЙНОЇ ТЕЛЕПОРТАЦІЇ!
```
**Проблема:** `load_room()` викликається кілька разів для тієї ж кімнати!

### Перевірка init_room():

```
✅ [Game] init_room() викликано для кімнати Canyon.tscn (виклик #1)
📍 [Game] Поточна позиція гравця ДО init_room: (100, 549)
📍 [Game] MetSys.last_player_position: (100, 549)
📍 [Game] Позиція гравця ПІСЛЯ очікування MetSys: (100, 549)
📍 [Game] Позиція гравця ПІСЛЯ init_room: (100, 549)
```
**Очікується:** 1 раз при завантаженні кімнати

```
⚠️ [Game] init_room() вже викликано для кімнати Canyon.tscn (виклик #2), пропускаємо
```
**Проблема:** `init_room()` викликається кілька разів для тієї ж кімнати!

### Перевірка повернення до Canyon:

```
🏜️ [Canyon] ✅ Прогрес виявлено (village_left), стейт = RELIC_PICKUP
🏜️ [Canyon] ⚠️ ВАЖЛИВО: При поверненні з Village ворота мають бути ВІДКРИТІ!
📍 [Game] Відстань до SavePoint: 1200.50 пікселів
✅ [Game] Гравець далеко від SavePoint, позиціонуємо на SavePoint
📍 [Game] Позиція гравця ПІСЛЯ позиціонування на SavePoint: (100, 549)
```
**Очікується:** При поверненні з Village до Canyon
