# 🔧 Виправлення переходу Canyon → Village

## Проблема

Перехід Canyon → Village має здійснюватись через проходи між сценами (MetSys room connections), а не через Portal/телепорт.

## Виправлення

### 1. Стан TO_VILLAGE - без телепорту

**Файл:** `SampleProject/Scripts/Gameplay/Scenes/Canyon.gd`

**Зміни:**
- `_on_to_village_state()` тепер не викликає телепорт
- Додано логування про те, що перехід здійснюється через проходи між сценами
- Гравець має йти до Village сам через проходи

### 2. Катсцена спуску до дороги

**Проблема:** Катсцена спуску (`Canyon_ExitCutscene`) не запускалася автоматично.

**Виправлення:**
- `_on_exit_cutscene_state()` тепер автоматично запускає діалог `Canyon_ExitCutscene`
- Після завершення катсцени встановлюється об'єктив "Спуститися до дороги"
- Перехід до DesertRoad відбувається після катсцени

### 3. Логіка переходів

**Canyon → Village:**
- Стан: `TO_VILLAGE`
- Діалог: `RoadToVillage` (тільки якщо гравець ще не був у Village)
- Перехід: через проходи між сценами (MetSys room connections)
- **НЕ використовується телепорт**

**Canyon → DesertRoad:**
- Стан: `EXIT_CUTSCENE` → `TO_DESERT_ROAD`
- Діалог: `Canyon_ExitCutscene` (катсцена спуску)
- Перехід: через `Game.load_room("DesertRoad.tscn")`

## Налаштування MetSys

Для правильного переходу Canyon → Village через проходи між сценами потрібно:

1. **Налаштувати room connections в MetSys Editor:**
   - Canyon room має бути з'єднана з Village room
   - Встановити правильні координати переходу
   - Налаштувати напрямок переходу (наприклад, справа Canyon → зліва Village)

2. **Переконатися, що в Canyon.tscn є правильні виходи:**
   - Ворота до Village (`Gate`) мають бути відкриті в стані `TO_VILLAGE`
   - Гравець може пройти через ворота до Village

3. **Переконатися, що в Village.tscn є правильні входи:**
   - Гравець має з'явитися в правильній позиції при переході з Canyon

## Перевірка

Після виправлень перевірте:

1. ✅ При стані `TO_VILLAGE` гравець НЕ телепортується до Village
2. ✅ Гравець може йти до Village через проходи між сценами
3. ✅ Катсцена спуску (`Canyon_ExitCutscene`) запускається автоматично
4. ✅ Після катсцени спуску гравець переходить до DesertRoad
5. ✅ Об'єктиви встановлюються правильно
